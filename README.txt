DIVYABHARATHI & JEGACHANDAR — WEDDING INVITATION WEBSITE

CONTENTS
- index.html: invitation page
- style.css: responsive design
- script.js: opening animation, countdown and WhatsApp sharing
- assets/couple-illustration.png: illustrated couple portrait
- assets/wedding-photo.jpg: original wedding photograph

PREVIEW
Extract the ZIP. Keep the assets folder beside the three website files.
Open index.html in a browser to preview.

PUBLISH WITH GITHUB PAGES
1. Create a PUBLIC GitHub repository named divyabharathi-weds-jegachandar.
2. Upload index.html, style.css, script.js and the entire assets folder.
3. Open repository Settings → Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. After GitHub publishes it, the website URL will be:
   https://YOUR-GITHUB-USERNAME.github.io/divyabharathi-weds-jegachandar/

WHATSAPP
Open the published URL and tap Share invitation on WhatsApp.
The page includes social sharing metadata. WhatsApp preview caching may take a little time after publishing.

VENUE LINKS
The directions buttons open Google Maps searches for the venue names. Please verify the exact map pin before forwarding the invitation.
